# قائمة الاختبار اليدوي على الجوال — Sinkly

هذه القائمة لما **لا يستطيع** الاختبار الآلي فحصه: الأذونات الحقيقية، القفل الفعلي فوق التطبيقات، الإشعارات، الكاميرا، والمتجر.
كل بند: الخطوات ← النتيجة المتوقعة. علّم ✅ أو ❌ واكتب ملاحظة عند الفشل.

> قبل البدء: احذف التطبيق من الجوال ثم ثبّته من جديد (تغييرات Kotlin/Swift لا تصل بـ hot restart).
> التطبيق مربوط الآن بـ RevenueCat Test Store: الشراء يُظهر نافذة RevenueCat التجريبية (نجاح / فشل / إلغاء) بدون دفع حقيقي. **لا تنشر قبل استبدال مفتاح `test_…` بالمفاتيح الحقيقية** (store/REVENUECAT_SETUP.md).

## 1) التثبيت الأول والإعداد (أندرويد + آيفون)
| # | الخطوات | المتوقع |
|---|---|---|
| 1.1 | افتح التطبيق لأول مرة | شاشة البداية ثم اختيار اللغة، ولغة الجوال محددة مسبقًا |
| 1.2 | غيّر اللغة إلى العربية ثم الإنجليزية | يتغير الاتجاه (يمين/يسار) فورًا وبدون نصوص مكسورة |
| 1.3 | أكمل الأسئلة حتى شاشة الأيام والوجبات | الأرقام والأوقات بالأرقام الإنجليزية، وعجلة الوقت بدقيقة واحدة |
| 1.4 | اضبط وقت وجبة 6:23 | يُحفظ 6:23 بالضبط (لا يتقرب إلى 6:25) |
| 1.5 | شاشة الإذن (أندرويد) | بطاقة سنكلي ← «متابعة» ← الإعدادات: «الظهور فوق التطبيقات» ثم «الوصول إلى الاستخدام» |
| 1.6 | (شاومي/ريدمي/بوكو فقط) | تظهر شاشة شاومي الحمراء «خطر» مع عدّاد 5 ثوانٍ — طبيعية، حدد المربع واضغط موافق |
| 1.7 | شاشة الإذن (آيفون) | تنبيه Apple الرسمي لمدة استخدام الجهاز داخل الإطار المضيء في المنتصف |
| 1.8 | اختيار التطبيقات | أندرويد: قائمة تطبيقاتك الحقيقية بالفئات · آيفون: منتقي Apple |
| 1.9 | خطوة التذكير قبل نهاية التجربة | يطلب إذن الإشعارات (أندرويد 13+ وآيفون) |
| 1.10 | شاشة الدفع | السعران ظاهران بدون تمرير، سطر «مجانًا حتى …» تحت الزر، لا زر «تخطّ الدفع» |
| 1.11 | اضغط X في شاشة الدفع | يظهر عرض الخصم مرة كل ضغطة، وأسفله نفس سطر «مجانًا حتى …» |
| 1.12 | اشترك (تجريبي) | احتفال ← شاشة الترحيب ← الرئيسية |

## 2) القفل الحقيقي (أهم قسم)
| # | الخطوات | المتوقع |
|---|---|---|
| 2.1 | تبويب الخطة: اجعل نهاية وجبة بعد دقيقتين ← حفظ | رسالة «تم حفظ الخطة» |
| 2.2 | انتظر حتى يمر الوقت ثم افتح تطبيقًا مقفلًا | أندرويد: بطاقة القفل فوق التطبيق خلال ثانية · آيفون: درع Apple بنفس الشخصية والنصوص |
| 2.3 | من بطاقة القفل اضغط «نظّف حوضي» | تفتح شاشة القفل في سنكلي (الشخصية + المسار الثلاثي) |
| 2.4 | اضغط X في أعلى شاشة القفل | يرجع إلى الرئيسية داخل سنكلي، والقفل ما زال قائمًا |
| 2.5 | افتح التطبيق المقفل مرة أخرى | تظهر شاشة القفل من جديد |
| 2.6 | زر الرجوع في أندرويد على شاشة القفل | يذهب الجوال لشاشته الرئيسية، لا يرجع للتطبيق المقفل |
| 2.7 | ابدأ «سباق الحوض» ← صوّر حوضًا نظيفًا | فحص الصورة ← احتفال ← فتح التطبيقات فورًا |
| 2.8 | صوّر حوضًا فيه صحون | رسالة «ما زالت هناك صحون» ولا يُفتح القفل |
| 2.9 | صوّر شاشة جوال آخر عليها حوض | رسالة «صوّر الحوض مباشرة» ولا يُفتح القفل |
| 2.10 | وضع الطيران ثم حاول التصوير | يُقال لك «لا يوجد إنترنت» **قبل** فتح الكاميرا، ولا تُحسب محاولة |
| 2.11 | أثناء القفل عدّل الخطة واحذف الوجبة التي قفلت | يُفتح القفل فورًا (قرارك: الخطة قابلة للتعديل دائمًا) |
| 2.12 | تطبيقات لا تُقفل أبدًا | الهاتف، الكاميرا، الإعدادات، الشاشة الرئيسية تعمل دائمًا |
| 2.13 | أعد تشغيل الجوال أثناء قفل | بعد التشغيل يبقى القفل قائمًا |
| 2.14 | أغلق سنكلي من قائمة التطبيقات الأخيرة | القفل يستمر في العمل |
| 2.15 | ثبّت تطبيقًا جديدًا من فئة مقفلة (أندرويد) | يُقفل تلقائيًا في وقت القفل |
| 2.16 | غيّر المنطقة الزمنية للجوال | أوقات الوجبات تبقى على ساعة الجوال الجديدة (19:00 تبقى 19:00) |

## 3) الإشعارات

## 7) آيفون — ما لم يُبنَ بعد
كود Swift لم يُترجم على Mac حتى الآن. على Mac: اتبع `ios/BLOCKING_SETUP.md`، شغّل `RunnerTests` (فيها اختبارات محرك القفل نفسها)، ثم كرر الأقسام 1–5 على آيفون حقيقي (Screen Time لا يعمل على المحاكي).
